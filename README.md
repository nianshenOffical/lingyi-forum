# 灵异复苏 · 观测者网络（《神秘复苏》同人 UI）

参考 B 站《五天手搓出灵异论坛》(BV12QnP61EYn) 的暗绿指挥中心风格，把《神秘复苏》里的灵异事件做成一张**可拖动、可缩放的三维地球**：52 个站点分布在六大洲，点标记看档案。

> 纯静态、离线可用；所有内容为虚构世界观展示，与原著版权方无关。

## 打开方式

双击 `index.html`（以 `file://` 打开即可，**不用起服务器**）。地球是 WebGL + Canvas 2D 双图层，无任何外部依赖/CDN。

## 页面

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `#/globe` | **全球态势（首页）** | 三维点阵地球：拖拽旋转、滚轮/按钮缩放、惯性、自动巡航；左侧事件列表（按等级 / 原著·原创筛选），右侧态势统计与大洲分布；点标记或列表项会**平滑飞向**该坐标并弹出档案 |
| `#/overview` | 观测总览 | 统计卡、各大洲伤亡柱状图、等级环形图（按数据实时生成）、近 30 天趋势、实时事件流、观测档案、本周压制记录 |
| `#/community` | 社区广场 | 五个板块、发帖框（演示态）、帖子流、好友 / 社区说明 / 在线成员 |
| `#/archive` | 灵异档案 | 52 条档案表格，按等级筛选 + 关键词搜索，点击行滑出全文 |
| `#/profile` | 驭鬼者档案 | 标签格档案、杀人规律与压制方式、观测数据侧栏 |

地球交互：左键拖动旋转、滚轮缩放（1×–5×）、双击或 `⟲` 复位、右下角 `＋/－` 缩放。悬停显示代号与高亮，点击打开档案。

## 文件

```
lingyi-forum/
├─ index.html
├─ README.md
└─ assets/
   ├─ style.css        全部样式（主题色在 :root）
   ├─ data.js          52 条事件 + 帖子 / 档案 / 统计
   ├─ globe.js         地球引擎（WebGL 点云 + 2D 标记层，无依赖）
   ├─ world-dots.js    40285 个陆地点（Natural Earth 陆地数据离线采样，base64 int16）
   └─ app.js           路由、渲染、交互
```

## 改内容

- 事件：`assets/data.js` 的 `sites`，字段 `c 编号 / n 代号 / lv 等级 / src 来源 / cty 国家 / pl 地点 / lng,lat 经纬度 / cont 大洲 / st 状态 / dead 伤亡 / date 首报 / d 概述 / r 危险规律[] / k 压制方式`。加一条就会同时出现在地球、列表和档案表里。
- 配色：`style.css` 的 `:root`（`--mint` 主青、`--red` 警报红、`--bg` 底色）。
- 地球密度：`world-dots.js` 由 `natural-earth` 陆地数据按 0.7° 采样生成；想更细可以重新采样（点数线性增长，40k 时性能约 60fps）。

## 部署到 GitHub Pages（让别人打开一个网址就能看）

### 方式一：网页上传（不用装 git，最省事）

1. 登录 GitHub → 右上角 `+` → **New repository**
2. 仓库名填比如 `lingyi-forum`，选 **Public**（私有仓库的 Pages 需要付费账号），**不要**勾选添加 README，点 Create
3. 进入空仓库 → **Add file → Upload files**
4. 把 `lingyi-forum` 文件夹里的 **`index.html`、`assets` 文件夹、`README.md`、`.nojekyll` 全部拖进去**
   - 关键：`index.html` 必须在**仓库根目录**，`assets` 要连文件夹一起上传
5. 下方点 **Commit changes**
6. 仓库 **Settings → 左侧 Pages → Build and deployment**
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/(root)** → **Save**
7. 等 1–2 分钟刷新该页，顶部会出现网址：

```
https://<你的用户名>.github.io/lingyi-forum/
```

把这个链接发给别人即可（手机也能开）。

### 方式二：本机 git 推送

```bash
cd D:\router\lingyi-forum
git init
git add .
git commit -m "灵异复苏 · 观测者网络"
git branch -M main
git remote add origin https://github.com/<用户名>/lingyi-forum.git
git push -u origin main
```

然后在网页上按方式一的第 6 步开启 Pages。
> 注意：本机直连 github.com 可能超时，需要走代理或改用 SSH（`ssh -T git@github.com` 能通再用 SSH 地址），网络不通就老老实实用方式一。

### 更新内容

改完本地文件后：网页上传覆盖 → Commit，或 `git add . && git commit -m "update" && git push`。
Pages 会在 1 分钟左右自动重新构建，**不需要重新配置**。

### 小提示

- URL 由「用户名 + 仓库名」决定；想换地址只能换仓库名。
- 想用自己域名：仓库根目录加一个内容为域名的 `CNAME` 文件，并在域名商处加 CNAME 解析。
- `.nojekyll` 已放好，避免 GitHub 用 Jekyll 处理静态文件。
- 这是同人二创，建议在仓库 Description 里写明「非官方，仅供学习交流，《神秘复苏》版权归作者佛前献花所有」。
